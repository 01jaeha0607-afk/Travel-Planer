## 1. 💡 기획 배경 : 어떤 문제를 왜 해결하려 했는가?
여행을 떠나는 것은 즐겁지만, **여행 일정을 짜는 과정은 막노동에 가깝습니다.** 블로그, 지도, 예약 사이트 등 수십 개의 창을 띄워놓고 동선을 짜고 예산을 계산하다 보면 여행을 가기도 전에 지치기 마련입니다.

**AI Travel Planner Pro**는 "누구와, 언제, 어떤 스타일로 갈 것인가?"라는 핵심 질문과 "해산물은 못 먹고, 걷는 건 싫어" 같은 **개인적인 요구사항을 완벽하게 반영**해 주는 나만의 전담 여행 플래너입니다. 

단순한 추천을 넘어 꿀팁(스타벅스 화장실 등)과 구체적인 예산안까지 제공하여, **여행 준비에 드는 스트레스와 시간을 획기적으로 줄이고자** 기획되었습니다.

<br>

## 2. ✨ 주요 기능 (Features)

| 기능 | 설명 |
|---|---|
| **📝 맞춤형 조건 입력** | 여행지, 월, 기간, 동행인, 인원수, 여행 스타일 등 세밀한 조건 설정 |
| **🧠 Gemini 2.5 Flash 연동** | 구글의 최신 생성형 AI를 활용한 빠르고 정확한 일정 생성 |
| **💡 로컬 꿀팁 제공** | 현지 날씨에 맞는 옷차림, 무료 화장실(스타벅스 등) 꿀팁 자동 포함 |
| **💰 스마트 예산 계산기** | 입력된 인원수에 맞춰 항공/숙박/식비 등 대략적인 경비를 표(Table)로 제공 |
| **✍️ 세부 요청사항 반영** | 알레르기, 특정 장소 방문 등 까다로운 요구사항을 프롬프트에 동적 반영 |
| **🌐 웹 기반 UI** | Streamlit을 활용하여 누구나 직관적으로 사용할 수 있는 깔끔한 웹 인터페이스 |

<br>

## 3. 🛠️ 실현 방법 (Tech Stack & Vibe Coding)

### 💻 사용 기술
* **Python**: 메인 개발 언어
* **Streamlit**: 프론트엔드 UI/UX 및 웹 서버 구동
* **Google Generative AI (Gemini API)**: LLM 텍스트 생성 및 데이터 추론

### 🤖 AI 도구 활용 (Vibe Coding) 과정
본 프로젝트는 코드 타이핑보다 로직과 프롬프트 설계에 집중하는 **바이브 코딩(Vibe Coding)** 방식으로 100% 개발되었습니다.

1. **초기 프로토타입 구현**: 가상의 데이터를 출력하는 Streamlit UI 뼈대 작성
2. **API 연동 및 트러블슈팅**: Gemini API 연동 중 발생한 경로 에러, API 키 400 에러, 모델 호환성 404 에러를 AI와의 티키타카를 통해 실시간으로 해결
3. **사용자 컨텍스트 확장**: 동행인, 여행 스타일 등 세부 입력 변수 추가
4. **프롬프트 엔지니어링**: AI가 표(Table) 형태로 예산을 출력하고, 해외여행 필수 꿀팁인 '스타벅스 화장실' 정보를 반드시 포함하도록 프롬프트 미세 조정(Tuning)

<br>

## 4. 📊 결과물 예시 (Output)

사용자가 조건을 입력하고 `[✨ 내 여행 일정 & 예산 만들기]` 버튼을 클릭하면 다음과 같은 결과가 마크다운(Markdown) 형태로 출력됩니다.

1. **여행 팁**: 해당 월의 날씨, 옷차림, 현지 주의사항
2. **숙소 추천**: 인원수와 동행인 특성에 맞는 구체적인 동네 및 객실 형태 추천
3. **일자별 상세 일정**: 오전/오후/저녁으로 나뉜 최적의 동선 및 로컬 맛집 추천
4. **화장실 꿀팁**: 동선 인근의 스타벅스 등 쾌적한 무료 화장실 정보
5. **예상 경비 표**: (N명 기준) 항목별 총 예상 예산표 (KRW 환산)

<br>

## 5. 🚀 특장점
* **초개인화된 결과물**: 정해진 템플릿이 아닌, 사용자의 '세부 요청사항' 텍스트를 AI가 분석하여 매번 새롭고 완벽하게 커스텀된 일정을 텍스트로 뽑아냅니다.
* **압도적인 속도**: Gemini 2.5 Flash 모델을 사용하여, 복잡한 계산과 일정 생성이 수 초 내에 완료됩니다.
* **디테일한 꿀팁**: 화장실 찾기가 힘든 해외여행의 특성을 고려해 '근처 스타벅스'를 탐색하도록 강제한 프롬프트 디테일이 돋보입니다.
