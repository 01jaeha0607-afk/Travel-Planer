1. 기획

어떤 문제를 왜 해결하려 했는가

여행을 준비하는 과정은 즐겁지만, 일정을 짜는 것은 상당한 시간과 노력이 소모되는 노동입니다. 수많은 블로그와 지도 앱을 오가며 동선을 짜고 예산을 계산하다 보면 쉽게 지치곤 합니다. 특히 "해산물 알레르기가 있다", "걷는 것을 싫어한다"와 같은 개인적인 요구사항을 반영해 주는 서비스는 찾아보기 어렵습니다.

본 프로젝트는 "가장 똑똑한 개인 전담 여행 플래너를 바탕화면에 두자"는 목표로 기획되었습니다. 사용자의 세밀한 요구사항을 완벽하게 반영하고, 여행지 필수 꿀팁과 예산안까지 단 몇 초 만에 생성하여 여행 준비의 스트레스를 획기적으로 줄이고자 했습니다.

2. 구성물

주요 기능 목록

기능 설명
조건 맞춤형 UI 여행지, 방문 월, 여행 기간, 동행인, 인원수, 여행 스타일을 직관적으로 선택 가능
세부 요청사항 반영 텍스트 입력을 통해 알레르기, 선호하는 뷰(View), 필수 방문지 등을 자유롭게 지시
스마트 예산 계산기 입력된 '인원수'를 바탕으로 항공/숙박/식비 등을 원화(KRW) 기준 표(Table)로 산출
현지 생존 꿀팁 해당 월의 날씨 및 옷차림 조언, 동선 인근 '무료 화장실(스타벅스 등)' 위치 정보 제공
초고속 텍스트 생성 Google Gemini 2.5 Flash 모델을 연동하여 수 초 이내에 완벽한 마크다운 형태의 결과물 출력

3. 실현 방법

사용 기술

Python 3.11 Streamlit Google Generative AI (Gemini)

AI 도구 활용 과정 (Vibe Coding)

  1. 아이디어 및 뼈대 구현: 구상한 아이디어를 자연어로 설명하여 Streamlit 기반의 UI 프로토타입 코드를 단숨에 생성.
  2. 트러블슈팅 및 API 연동: 개발 과정에서 발생한 환경 변수(PATH) 오류, API 키 400 에러, 모델 명칭 404 에러 등을 AI와 실시간으로 대화하며 해결(Troubleshooting).
  3. 프롬프트 엔지니어링: 단순한 일정 추천을 넘어, AI에게 "예산안을 표로 작성할 것", "근처 스타벅스 화장실 위치를 포함할 것" 등 역할과 출력 형식을 강제하는 프롬프트 최적화 수행.
  4. 기능 고도화: 초기 버전 완성 후 '세부 요청사항 텍스트 박스', '인원수 기반 예산 계산' 기능을 추가로 요청하여 코드를 빠르고 유연하게 업그레이드.

완성된 프로그램 스크린샷 및 설명

프로그램 실행 시 직관적인 웹 인터페이스가 나타나며, 모든 조건을 입력한 후 버튼을 누르면 화면 하단에 마크다운 형식으로 렌더링된 깔끔한 여행 일정표와 예산안이 출력됩니다.

5. 특장점

  • 초개인화된 일정: 정해진 템플릿 검색이 아닌 생성형 AI를 활용하므로, 어떠한 기상천외한 세부 요구사항이라도 유연하게 일정에 녹여냅니다.
  • 마이크로 디테일 (Micro-detail): 단순히 맛집만 나열하는 것이 아니라 화장실 찾기, 해당 월의 옷차림 등 실제 여행자가 현지에서 가장 필요로 하는 '생존 정보'를 짚어줍니다.
  • No-code에 가까운 진입장벽: Streamlit을 사용하여 HTML/CSS/JS 작성 없이 파이썬만으로 미려한 웹 앱을 완성했습니다.

6. 한계점

  • API 의존성: Google Gemini API 키가 반드시 필요하며, 인터넷 연결이 필수적입니다.
  • 할루시네이션(환각): AI 특성상 이미 폐업한 식당을 추천하거나, 예산안의 물가가 실제 현지 물가와 미세한 오차가 발생할 수 있습니다.
  • 실시간 예약 불가: 일정표와 예산을 제공하지만 항공권이나 숙소를 클릭 한 번에 예약하는 결제 시스템과는 연동되어 있지 않습니다.

7. Todo (향후 개선 방향)

  • 지도 플랫폼 연동: AI가 텍스트로 짜준 동선을 Google Maps나 카카오맵 API로 화면에 시각적으로 그려주는 기능 추가.
  • 문서 내보내기: 생성된 일정과 예산표를 모바일에서 보기 편하도록 PDF나 텍스트 파일로 다운로드하는 버튼 추가.
  • 다국어 지원: 여행지의 현지 언어(예: 일본어, 프랑스어)로 된 간단한 주문 회화표를 결과물 마지막에 자동으로 첨부하는 기능.
